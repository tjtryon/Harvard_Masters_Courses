## Mystery Method Analysis

```java
public static void mystery(int[] a, int[] b) {
    // Loop through each index of array 'a' from start to end
    for (int i = 0; i < a.length; i++) {
        // Add to each element of 'a' the corresponding element from 'b' in reverse order
        // b.length - 1 - i creates reverse indexing:
        // - b.length - 1 gives the last valid index of array b
        // - Subtracting i moves backwards from the end
        // - When i=0: b[b.length-1-0] = b[4] (last element)
        // - When i=1: b[b.length-1-1] = b[3] (second to last)
        // - When i=2: b[b.length-1-2] = b[2] (middle element)
        // - And so on...
        a[i] += b[b.length - 1 - i];
    }
}
```

Given arrays:
- `a1 = {1, 3, 5, 7, 9}`
- `a2 = {1, 4, 9, 16, 25}`

## Why This Works - Detailed Technical Analysis

### **1. Reverse Indexing Formula: `b[b.length - 1 - i]`**

This formula creates a mathematical mapping from forward indices to reverse indices:

**Mathematical Explanation:**
- `b.length` = 5 (total number of elements)
- `b.length - 1` = 4 (index of last element, since arrays are 0-indexed)
- `b.length - 1 - i` = 4 - i (creates reverse mapping)

**Index Transformation:**
```
Forward index (i) → Reverse index (4-i) → Element accessed
i = 0 → 4-0 = 4 → b[4] = 25 (last element)
i = 1 → 4-1 = 3 → b[3] = 16 (second to last)
i = 2 → 4-2 = 2 → b[2] = 9  (middle element)
i = 3 → 4-3 = 1 → b[1] = 4  (second element)
i = 4 → 4-4 = 0 → b[0] = 1  (first element)
```

### **2. Array Modification Process: `a[i] += b[b.length - 1 - i]`**

The `+=` operator performs **in-place modification**:
- Reads the current value of `a[i]`
- Adds the value from `b[b.length - 1 - i]`
- Stores the result back in `a[i]`
- This is equivalent to: `a[i] = a[i] + b[b.length - 1 - i]`

### **3. Memory and Reference Behavior**

**Pass by Reference:** Arrays in Java are objects, so when passed to methods:
- The method receives a **reference** to the original array, not a copy
- Changes made inside the method **directly modify** the original array
- The array `a` passed to `mystery()` is the same array object in memory
- No new array is created - we're modifying the existing array's contents

**Memory Impact:**
- Space complexity: O(1) - no additional arrays created
- Time complexity: O(n) - single pass through array `a`

### **4. Algorithmic Pattern**

This creates a **cross-addition pattern**:
```
Original arrays:
a: [1, 3, 5, 7, 9]    (indices 0,1,2,3,4)
b: [1, 4, 9,16,25]    (indices 0,1,2,3,4)

Addition pattern:
a[0] += b[4]  →  1 + 25 = 26
a[1] += b[3]  →  3 + 16 = 19
a[2] += b[2]  →  5 + 9  = 14
a[3] += b[1]  →  7 + 4  = 11
a[4] += b[0]  →  9 + 1  = 10
```

### **5. Why the Formula Works Mathematically**

For any array of length `n`, the reverse index formula `n - 1 - i` ensures:
- **Boundary safety**: Always produces valid indices (0 ≤ result ≤ n-1)
- **Perfect reversal**: Maps first element to last, second to second-last, etc.
- **Symmetric mapping**: The middle element (if odd length) maps to itself

**Proof of correctness:**
- When `i = 0`: `n-1-0 = n-1` (last valid index)
- When `i = n-1`: `n-1-(n-1) = 0` (first index)
- All intermediate values produce valid indices between 0 and n-1

This formula is a fundamental computer science technique for **array reversal** and **mirror operations**.
